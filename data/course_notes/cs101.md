# CS101 — Introduction to Programming

## Variables and types
A variable is a name bound to a value. Python is dynamically typed, so a name can be rebound to a value of a different type at any time. The common built-in types are int, float, str, bool, list, dict, tuple and set.

## Lists versus tuples
A list is mutable: you can append, remove and reassign elements after creation. A tuple is immutable: once created its contents cannot change. Tuples can be used as dictionary keys because they are hashable; lists cannot.

## Dictionaries
A dictionary maps keys to values and offers average O(1) lookup, insertion and deletion. Keys must be hashable. Since Python 3.7 dictionaries preserve insertion order.

## Loops
A for loop iterates over a sequence. A while loop repeats as long as a condition holds. Use `break` to leave a loop early and `continue` to skip to the next iteration.

## Functions
A function groups reusable logic behind a name. Arguments can be positional or keyword. Default argument values are evaluated once at definition time, which is why a mutable default like `def f(x=[])` is a classic bug.

## Scope
Names resolve using the LEGB rule: Local, Enclosing, Global, Built-in. Assigning to a name inside a function makes it local unless declared `global` or `nonlocal`.

## Recursion
A recursive function calls itself on a smaller input and needs a base case to terminate. Every call adds a stack frame, so deep recursion can raise RecursionError. Many recursive solutions can be rewritten iteratively.

## Big-O notation
Big-O describes how running time grows with input size, ignoring constants. Common classes in order: O(1) constant, O(log n) logarithmic, O(n) linear, O(n log n), O(n^2) quadratic, O(2^n) exponential.

## Searching
Linear search checks every element and is O(n). Binary search requires a sorted sequence, halves the range each step and is O(log n).

## Sorting
Bubble sort and insertion sort are O(n^2) and rarely used in practice. Merge sort and heap sort are O(n log n) in the worst case. Python's built-in sort is Timsort, which is O(n log n) and fast on partly sorted data.

## Stacks and queues
A stack is last-in-first-out; push and pop happen at the same end. A queue is first-in-first-out; items enter at one end and leave at the other. Python's collections.deque supports both efficiently.

## Exceptions
Use try/except to handle errors you can recover from. Catching bare `except:` hides real bugs. `finally` always runs and is used for cleanup such as closing files.

## File handling
Open files with a `with` statement so they close automatically even if an error occurs. Read modes include 'r' for text and 'rb' for binary.

## Classes and objects
A class defines the structure and behaviour of objects. `__init__` initialises a new instance. Instance attributes belong to one object; class attributes are shared by all instances.

## Inheritance
A subclass inherits behaviour from a parent class and can override methods. Prefer composition over inheritance when the relationship is "has a" rather than "is a".

## Testing
A unit test checks one unit of behaviour in isolation. Good tests are fast, deterministic and independent of each other. Test the edge cases: empty input, a single element, and the largest input you expect.

## Version control
Git tracks changes as commits. A branch is a movable pointer to a commit. Commit small, coherent changes with messages that explain why, not what.
